
## Project Screenshots

The project was tested using two chat clients, Alice and Bob.

### 1. AES Encryption and Decryption
Verified that messages can be encrypted and decrypted
successfully using AES-256-GCM.

### 2. Encrypted Message Logging
Demonstrated server logging of connection events and
encrypted message activity without exposing plaintext.

### 3. Alice Sending a Message
Demonstrated a client sending an encrypted message
through the TCP server.

### 4. Bob Receiving a Message
Verified that a second client successfully received
and decrypted Alice's message.
